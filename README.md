Real Estate Housing Price Prediction

Datheon Internship — Task 2

Objective

Predict California housing prices using machine learning regression models.

Technologies

- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Google Colab

Models

- OLS Linear Regression
- Ridge Regression
- Lasso Regression

Project Workflow

1. Dataset exploration and correlation heatmap
2. Data preprocessing and feature engineering
3. Training and testing data split
4. Hyperparameter tuning using GridSearchCV
5. Model comparison using RMSE, MAE and R²
6. Actual-versus-predicted and residual-error plots

Results

- RMSE: 66788.2960
- MAE: 47282.1110
- R²: 0.6596

Deliverable

A Jupyter notebook containing the code, model evaluation and visualizations.
